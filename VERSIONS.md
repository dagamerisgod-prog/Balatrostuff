# Balatrostuff

An open-source Steamodded content mod for Balatro. This mod is a fan-made project and is not affiliated with LocalThunk or Playstack.

## Releases

- **v0.1.0** — original 28-Joker pack, preserved from the previously installed mod snapshot.
- **v0.2.0** — adds eight deliberately overpowered Jokers and four custom Tarot consumables.
- **v0.3.0** — adds eight more Jokers, four operator/reality-breaking Tarot consumables, three unfair stakes, and two new decks.

See [README.md](README.md) for content details and installation notes. The `v0.1.0` and `v0.2.0` Git tags mark the preserved versions.
