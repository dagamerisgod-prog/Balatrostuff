# Balatrostuff

A standalone Steamodded content pack with **44 Jokers, 8 deliberately overpowered Tarot consumables, 3 unfair custom stakes, and 2 new decks**. The update adds operator-themed scoring, massive flat bonuses, huge Mult multipliers, hand-level upgrades, Joker creation, cash injections, stronger blind scaling, and extra starting resources. It uses built-in game atlases as placeholder artwork, so the pack does not need custom sprite sheets to register its content.

## Included Jokers

Lucky Seven, Coin King, Card Shark, Jester's Luck, The Matador, Pixel Perfect, Vortex, The Gambler, Double Trouble, The Alchemist, Time Thief, Void Walker, The Architect, Soulbound, The Collector, Bouncer, The Dreamer, Chaos, The Eternal, Reroll King, Marble Giant, Last Laugh, Lucky Penny, Glass Cannon, Full House Fund, Ace in the Hole, Night Shift, Tiny Titan, Multiverse Engine, Seven Singularity, Infinite Wallet, Hand of Gods, The Red Button, Planet Eater, Glass God, Joker Black Hole, Operator: PLUS, Operator: TIMES, Operator: POWER, Operator: FACTORIAL, Blue Screen of God, Ante Eater, Duplicate Machine, and Infinity Loop.

## New consumables

- **Money Printer** — gain $100.
- **Hand of Fate** — upgrade every poker hand five levels.
- **Joker Festival** — create up to two random Jokers if slots are available.
- **The Big Bang** — gain three additional hands and $50.
- **Operator: Add** — gain $777 and a large chip injection.
- **Operator: Multiply** — upgrade every poker hand ten levels.
- **Operator: Power** — create up to three Polychrome Jokers.
- **Reality Reset** — gain $1000 and a Spectral card.

## Unfair stakes

- **Apocalypse Stake** — 2x ante scaling and $2 less starting money.
- **Cataclysm Stake** — 4x ante scaling and $4 less starting money.
- **UNFAIR Stake** — 8x ante scaling and $8 less starting money.

## New decks

- **Operator Deck** — extra Joker and consumable slots.
- **Chaos Deck** — $100, extra hands and discards.

## Install for testing

1. Your folder already contains Steamodded (`smods-26.829.0`) and Lovely-related files, and it has many other mods installed.
2. The mod is installed at `%AppData%/Balatro/Mods/Balatrostuff/` with `Balatrostuff.json` and `main.lua`.
3. Launch the game, check the Mods menu for Balatrostuff, then start a fresh run and look for the new Jokers in the shop.

The v0.3.0 additions have not yet been confirmed in a live run. Cards and deck backs use built-in artwork as placeholders. If the game reports an API error, check the newest game log in `%AppData%/Balatro/logs/` and adjust the pack to that installed version.

The standard Steamodded setup does not require signing in to Steam, but the exact game build still needs to be compatible with the installed injector and mod loader. For current setup details, see the [Steamodded documentation](https://docs.smods.dev/).
