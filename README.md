# Balatrostuff

A standalone Steamodded content pack with **36 Jokers and 4 deliberately overpowered Tarot consumables**. The new additions include huge flat bonuses, exponential Mult, hand-level upgrades, Joker creation, and cash injections. It uses the game's built-in Joker and Tarot atlases as placeholder artwork, so the pack does not need separate image assets to load.

## Included Jokers

Lucky Seven, Coin King, Card Shark, Jester's Luck, The Matador, Pixel Perfect, Vortex, The Gambler, Double Trouble, The Alchemist, Time Thief, Void Walker, The Architect, Soulbound, The Collector, Bouncer, The Dreamer, Chaos, The Eternal, Reroll King, Marble Giant, Last Laugh, Lucky Penny, Glass Cannon, Full House Fund, Ace in the Hole, Night Shift, Tiny Titan, Multiverse Engine, Seven Singularity, Infinite Wallet, Hand of Gods, The Red Button, Planet Eater, Glass God, and Joker Black Hole.

## New consumables

- **Money Printer** — gain $100.
- **Hand of Fate** — upgrade every poker hand five levels.
- **Joker Festival** — create up to two random Jokers if slots are available.
- **The Big Bang** — gain three additional hands and $50.

## Install for testing

1. Your folder already contains Steamodded (`smods-26.829.0`) and Lovely-related files, and it has many other mods installed.
2. The mod is installed at `%AppData%/Balatro/Mods/Balatrostuff/` with `Balatrostuff.json` and `main.lua`.
3. Launch the game, check the Mods menu for Balatrostuff, then start a fresh run and look for the new Jokers in the shop.

The source and metadata have been updated, but the new content has not yet been confirmed in a live run. Cards currently use built-in Joker/Tarot artwork as placeholders. If the game reports an API error, check the newest game log in `%AppData%/Balatro/logs/` and adjust the pack to that installed version.

The standard Steamodded setup does not require signing in to Steam, but the exact game build still needs to be compatible with the installed injector and mod loader. For current setup details, see the [Steamodded documentation](https://docs.smods.dev/).
